# 🚨 Financial Fraud Detection System

An end-to-end AI-powered Financial Fraud Detection Platform built using Machine Learning, XGBoost, Streamlit, and Interactive Analytics Dashboards.

---

## 📌 Project Overview

Financial fraud causes billions of dollars in losses every year. This project helps identify potentially fraudulent transactions using machine learning models and provides advanced analytics, explainability, forecasting, and monitoring dashboards.

The system enables:

- Fraud Detection using XGBoost
- Real-Time Fraud Monitoring
- Fraud Risk Scoring
- Fraud Forecasting
- Explainable AI (XAI)
- Fraud Analytics
- Graph Analysis
- Interactive Visualizations

---

## 🎯 Objectives

- Detect fraudulent transactions accurately.
- Reduce false positives.
- Explain fraud predictions.
- Monitor fraud trends in real time.
- Forecast future fraud activity.
- Provide actionable business insights.

# 🚀 Installation

Clone repository:

```bash
git clone https://github.com/your-username/Financial-Fraud-Detection.git
```

Move into project:

```bash
cd Financial-Fraud-Detection
```

Create virtual environment:

```bash
python -m venv venv
```

Activate environment:

### Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
streamlit run app.py
```

# 📊 Dataset

Dataset Used:

Bank Account Fraud (BAF) Dataset

Features include:

- Income
- Customer Age
- Credit Risk Score
- Transaction Amount
- Device Information
- Email Similarity
- Foreign Request
- Session Details

Target Variable:

```text
fraud_bool
```

- 0 → Legitimate
- 1 → Fraudulent
